# Scripts

## extract

Extract archive files without remembering archive-specific commands.

Supported:

- tar.gz
- tar.xz
- tar.bz2
- zip
- 7z
- rar

## update

Update system packages.

Actions:

- Check internet
- Update pacman packages
- Update AUR packages
- Show orphan packages

Does not automatically remove packages.

## cleanup

Clean unnecessary system leftovers.

Actions:

- Clean pacman cache
- Vacuum system logs
- Check orphan packages
- Remove thumbnail cache

Does not automatically remove packages.
